AgriSentinel - Project Documentation & Development Log1. Project Overview & ArchitectureAgriSentinel is a precision agriculture analytics and machine learning pipeline designed to monitor crop health, soil influence, and water stress by combining satellite Earth observation data with historical ground weather metrics.System ArchitectureThe project follows a strict separation of concerns:src/ (Production Engine): Contains modular, reusable Python utility scripts for data ingestion, spatial resampling, API integrations, and feature engineering.notebooks/ (Exploratory Dashboard): Serves as an analytical interface that imports backend functions from src/ to plot high-resolution heatmaps and validate data.data/ (Caching Layer): Local geotiff and climate data storage layer to avoid redundant API downloads.2. Core Modules & Component StatusA. Satellite Engine (src/satellite_api.py)Handles the complete automated lifecycle of satellite data:STAC Catalog Querying: Searches Microsoft Planetary Computer’s STAC API for Sentinel-2 L2A satellite captures over target coordinates ($\text{lat}, \text{lon}$) with cloud cover $< 15\%$.Automated Band Ingestion: Streams missing satellite bands into local .tif files.Bilinear Spatial Resampling: Automatically resamples $20\text{m}$ resolution bands up to $10\text{m}$ resolution to ensure exact matrix alignment across layers.Multi-Index Calculation: Computes array representations for three primary feature-engineered vegetation parameters.B. Weather Pipeline (src/weather_api.py)Manages meteorological data retrieval:Historical Climate Extraction: Queries meteorological APIs for ground-level climate metrics (min/max/average temperatures, precipitation, relative humidity, solar radiation, wind speed).Data Structuring: Formats multi-day historical weather tables for future time-series alignment with satellite capture dates.C. Visual Dashboard (notebooks/01_eda_and_ndvi.ipynb)Provides a 3-panel comparative heatmap display (NDVI vs. SAVI vs. NDWI) to visually cross-analyze crop health against moisture levels across farm regions.4. Feature Engineering & Mathematical FormulasFeature IndexLight Spectrum Bands UsedPrimary FormulaAgricultural MeasurementNDVI (Normalized Difference Vegetation Index)NIR (Band 8, $10\text{m}$) & RED (Band 4, $10\text{m}$)$$\text{NDVI} = \frac{\text{NIR} - \text{RED}}{\text{NIR} + \text{RED} + 1e-6}$$Overall plant health, photosynthetic activity, and canopy density.SAVI (Soil Adjusted Vegetation Index)NIR (Band 8, $10\text{m}$) & RED (Band 4, $10\text{m}$)$$\text{SAVI} = \frac{\text{NIR} - \text{RED}}{\text{NIR} + \text{RED} + L} \times (1.0 + L) \quad (L = 0.5)$$Vegetation health corrected for bare-soil background reflection in sparse fields.NDWI (Normalized Difference Water Index)NIR (Band 8, $10\text{m}$) & SWIR (Band 11, $20\text{m}$)$$\text{NDWI} = \frac{\text{NIR} - \text{SWIR}}{\text{NIR} + \text{SWIR} + 1e-6}$$Internal leaf moisture content, crop hydration, and drought stress detection.5. ### D. Time Alignment & Feature Fusion Pipeline (`src/data_alignment.py`)
Fuses 2D spatial satellite matrices with 1D temporal weather time-series:
1. **Spatial Aggregation:** Computes statistical distributions (`mean`, `std`, `min`, `max`, `p25`, `p75`) across billions of pixels for NDVI, SAVI, and NDWI.
2. **Temporal Aggregation:** Calculates rolling weather windows (`3d`, `7d`, `14d` cumulative precipitation, mean/max temperatures, relative humidity, max wind speed) relative to the satellite capture date.
3. **Master Dataset Export:** Merges climate metrics and satellite metrics into a unified feature row and appends to `data/master_dataset_<lat>_<lon>.csv`.
